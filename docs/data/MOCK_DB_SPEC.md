# Спецификация данных для In-Memory Mock DB

Настоящий документ является техническим заданием на создание встроенной базы данных (In-Memory Mock DB). Все текстовые данные и ИИ-теги заполняются **строго на русском языке**, чтобы ИИ-оркестратор мог выполнять семантический поиск без накладных расходов на перевод.

## 1. Сущность: Отели (Hotels)

*   `id` (string): Уникальный текстовый идентификатор. Пример: `hotel_ostrovok_comfort_kazan`
*   `name` (string): Официальное название для вывода пользователю. Пример: `Отель Полянка Комфорт`
*   `city` (string): Город нахождения (жесткий фильтр). Пример: `Казань`
*   `stars` (int): Звездность отеля (от 1 до 5). Пример: `4`
*   `price_per_night` (float): Базовая стоимость проживания за одну ночь. Пример: `6500.00`
*   `amenities` (array of strings): Массив стандартных удобств. Пример: `["wifi", "бассейн", "парковка"]`
*   `semantic_tags` (array of strings): ИИ-теги для гибкого семантического поиска. Пример: `["тихий", "семейный"]`
*   `review_verdict` (string): Выжимка из отзывов для аргументации выбора. Пример: `Хвалят за тишину, ругают за лифт`
*   `coordinates` (object): Географические координаты для правого виджета карты.
    *   `latitude` (float)
    *   `longitude` (float)
*   `is_available` (bool): Флаг доступности номеров. Пример: `true`

## 2. Сущность: Транспорт (Transport)

*   `id` (string): Уникальный идентификатор рейса или поезда. Пример: `flight_su_100`
*   `type` (string): Тип ТС (`самолет` или `поезд`). Пример: `самолет`
*   `company` (string): Название компании-перевозчика. Пример: `Аэрофлот`
*   `from_city` (string): Город отправления. Пример: `Москва`
*   `to_city` (string): Город прибытия. Пример: `Казань`
*   `departure_time` (string): Дата/время отправления в формате ISO 8601. Пример: `2026-11-14T08:30:00Z`
*   `arrival_time` (string): Дата/время прибытия в формате ISO 8601. Пример: `2026-11-14T10:00:00Z`
*   `price` (float): Полная стоимость одного билета. Пример: `5400.00`
*   `class_type` (string): Класс обслуживания (`эконом`, `бизнес`, `плацкарт`, `купе`). Пример: `эконом`
*   `semantic_tags` (array of strings): ИИ-теги для умной фильтрации. Пример: `["быстрый", "утренний"]`
*   `seats_left` (int): Количество оставшихся мест. Пример: `15`

## 3. Дополнительные сущности для ИИ-путеводителя

### 3.1 Активности и достопримечательности (Activities)
*   `id` (string): ID места. Пример: `place_kazan_kremlin`
*   `city` (string): Город. Пример: `Казань`
*   `name` (string): Название. Пример: `Казанский Кремль`
*   `category` (string): Тип (`музей`, `парк`, `экскурсия`, `ресторан`). Пример: `музей`
*   `price` (float): Стоимость входа (0.0 если бесплатно). Пример: `500.00`
*   `time_spent` (float): Среднее время посещения в часах. Пример: `2.5`
*   `semantic_tags` (array of strings): ИИ-теги под интересы. Пример: `["история", "красивый-вид"]`

### 3.2 Прогноз погоды (Weather_Forecast)
*   `city` (string): Город. Пример: `Санкт-Петербург`
*   `date` (string): Дата прогноза (YYYY-MM-DD). Пример: `2026-11-14`
*   `temp_celsius` (int): Средняя температура. Пример: `17`
*   `condition` (string): Описание условий (`солнечно`, `дождь`). Пример: `дождь`
*   `clothing_recommendation` (string): Подсказка ИИ для проявления заботы. Пример: `ветровка, зонт`

### 3.3 Локальный контекст (Local_Context)
*   `city` (string): Город. Пример: `Санкт-Петербург`
*   `context_type` (string): Категория нюанса (`транспорт`, `праздники`). Пример: `транспорт`
*   `title` (string): Суть особенности. Пример: `Развод мостов`
*   `description` (string): Текст предупреждения. Пример: `Ночью мосты разводятся...`
*   `impact_level` (string): Степень влияния на планы (`низкая`, `средняя`, `критическая`). Пример: `средняя`
